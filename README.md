# Trabalho-Individual-Engenharia-de-Software

## 📌 Descrição
Este projeto foi desenvolvido como parte da disciplina de Engenharia de Software.  
O objetivo é aplicar conceitos de controle de versão utilizando Git e GitFlow, além de desenvolver funcionalidades em C++ com testes.

---

## 🛠️ Tecnologias utilizadas
- C++
- Git / GitHub
- Makefile

---

## 📁 Estrutura do projeto

├── src/ # Código fonte principal
├── include/ # Arquivos de cabeçalho
├── bin/ # Arquivos compilados
├── test/ # Testes do sistema
└── doc/ # Documentação
